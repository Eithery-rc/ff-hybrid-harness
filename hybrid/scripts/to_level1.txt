# to_level1.txt - from game start to gameplay in the first single-player mission (C01A), then a few steps.
#
# Tested 2026-10-22 on the vanilla game (zero hooks) at time_scale 4 with frame_dump, Russian menus, 1280x720
# windowed, off-screen. Times are seconds on the loader's clock (real time x time_scale), counted from the last
# satisfied wait_scene. Keyboard only: every menu here is driven by the arrows and RETURN, and opens with a sensible
# item highlighted.
#
# Flow (scene lines as in ff_hybrid.log):
#   FF-Intro.ZIP            logos, then the opening cinematic; ESC skips straight to the menu
#   StartLoader.ZIP, FF-Startup.ZIP   main menu: START* OPTIONS EXIT CREDITS
#   RETURN                  player profile: NEW* LOAD DELETE, BACK
#   RETURN                  difficulty: 4 lines, the 3rd (Freedom Fighter) highlighted; UP UP = the easiest
#   RETURN                  new game: name "FREEDOM FIGHTER" (default), START GAME*, BACK
#   RETURN                  a profile with that name exists after the first run: "overwrite?" NO* YES,
#                           so RIGHT RETURN; on a machine without it these two presses fall on the autosave screen
#   Cutscenes/MovieCuts/FF_MC01A/FF_MC01A_MAIN.ZIP   intro movie, ESC skips it
#   Singleplayer/C01A/Loader.ZIP, SinglePlayer/C01A/FF-C01A_MAIN.ZIP   the mission; control about 4 s later
# Each run writes Profiles\FREEDOM FIGHTER.dat in %APPDATA%\IO Interactive\Freedom Fighters (a fresh new game).
# Vanilla timing at x4: FF-C01A_MAIN at about t=140 from the start.
